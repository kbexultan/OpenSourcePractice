# OpenSourcePractice
ОпенСорс практика на 0,5 баллов

## Installation

### Prerequisites

- [Git](https://git-scm.com/downloads) installed on your computer
- A GitHub account, if you want to contribute

To check that Git is installed, run:

```bash
git --version
```

### Getting the project

1. Clone the repository:

   ```bash
   git clone https://github.com/kbexultan/OpenSourcePractice.git
   ```

2. Go to the project folder:

   ```bash
   cd OpenSourcePractice
   ```

3. To get the latest changes later, run:

   ```bash
   git pull
   ```
